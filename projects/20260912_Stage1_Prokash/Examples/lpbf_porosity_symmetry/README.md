# LPBF Porosity Scaling-Symmetry Discovery

Discover the hidden scaling symmetry in Laser Powder Bed Fusion (LPBF)
additive-manufacturing porosity data using the PyDimension Stage1
pipeline.

## Motivation

The companion notebook
[`../4_plot_3d-ZGAN(1).ipynb`](../4_plot_3d-ZGAN(1).ipynb)
takes experimental porosity measurements for five alloys (Al2024,
Al6061, Cu, SS304, Ti64) processed at many (P, V) combinations and
collapses the "porosity landscape" onto a single logistic curve in a
hand-picked dimensionless variable:

```
Pi = (Lv * rho * A * P * V) / (k^2 * (Tb - Tm)^2)
```

This is the classic **"normalised enthalpy"** used in the LPBF
printability literature (Gan et al. 2021, Xie et al. 2022 etc.) to
separate conduction / vapour-depression / keyhole regimes across
materials.  The collapse is excellent, which is *evidence* of a scaling
symmetry — but the notebook never extracts the symmetry itself.  This
example closes that gap: it recovers the invariance directly from the
experimental data, with no formula for `Pi` supplied.

## Physics background

The pore fraction `f` left in a single-track LPBF deposit depends on
seven physical inputs with four fundamental dimensions (M, L, T, K):

| Variable              | Symbol | Units    | Dimensions        |
|-----------------------|--------|----------|-------------------|
| Laser power           | P      | W        | kg·m²·s⁻³         |
| Scan speed            | V      | m/s      | m·s⁻¹             |
| Absorptivity          | A      | —        | dimensionless     |
| Metal density         | rho    | kg/m³    | kg·m⁻³            |
| Thermal conductivity  | k      | W/(m·K)  | kg·m·s⁻³·K⁻¹      |
| Latent heat of vap.   | Lv     | J/kg     | m²·s⁻²            |
| Superheat (Tb - Tm)   | dT     | K        | K                 |

By the **Buckingham Pi theorem**, `7 − 4 = 3` independent dimensionless
groups control `f`.  One of them is `Pi`; for the pore-fraction response
it is the dominant one (the notebook shows it collapses all five alloys).

A **scaling symmetry** acts by simultaneously rescaling several physical
variables in a way that leaves every dimensionless group unchanged.
Recovering the Lie-algebra generators of this group reveals *which*
variables can trade off without moving the experimental point on the
master curve.

## Dataset

`dataset_lpbf.csv` is generated by extracting the raw
`(material, P, V, Pore)` table embedded in the notebook and joining it
against the per-material thermophysical properties
(`k, rho, cp, Tm, Tb, Lv, A`) that the notebook defines at the top of
its first code cell.  Laser power is in watts; scan speed is converted
from mm/s to m/s; `dT = Tb − Tm`; `Pi` is precomputed for reference.

* 232 experimental points
* 5 alloys (Al2024, Al6061, Cu, SS304, Ti64)
* Pore fraction in [0, 1]

Rows for which the notebook reports no measurement (empty `Pore`) are
dropped.

## Pipeline

1. **Data loading** — read the CSV, drop rows with non-positive `Pi`
2. **Normalization** — min-max scaling
3. **Latent dimension discovery** — autoencoder sweep (expected:
   k* = 1, since the notebook's logistic collapse already shows that
   porosity is a 1-D function of `log Pi`)
4. **Symmetry identification** — competitive encoder training
   (expected: **scaling** wins by a large margin)
5. **Generator extraction** — null-space of the linear log-space
   encoder ⇒ 6 scaling directions (`n_inputs − n_latent = 7 − 1`) that
   leave `Pi` invariant
6. **Visualization** — 3-panel summary figure:
   * `log10(Pi)` vs pore fraction (collapse + logistic fit),
   * validation MSE for translational / rotational / scaling,
   * generator orbits over the two most-weighted variables

## Usage

```bash
cd projects/20260912_Stage1_Prokash/Examples/lpbf_porosity_symmetry

python discover_symmetry.py --data dataset_lpbf.csv

# With a multi-layer encoder for the latent-dimension sweep:
python discover_symmetry.py --data dataset_lpbf.csv --encoder-hidden 64 32

# With Pi-group augmentation (inject known normalised enthalpy as a basis):
python discover_symmetry.py --data dataset_lpbf.csv --pi-basis
```

## Expected results

* **Symmetry type**: scaling (large loss gap vs translational/rotational)
* **Latent dimension**: `k* = 1` (pore fraction ≈ logistic of `log Pi`)
* **Dominant generator weights**: a direction proportional to
  `[P, V, A, rho, k, Lv, dT] → [+1, +1, +1, +1, −2, +1, −2]` (up to an
  overall sign / rescaling) — i.e. the log-exponents of the
  notebook's `Pi`
* **Physical meaning**: doubling `P` and halving `V` (or doubling `k`
  and `dT` together, etc.) moves along an orbit on which pore fraction
  is invariant — *exactly* the "P·V·Lv·rho·A / k²·dT²" trade-off that
  the notebook exploited to collapse the five-material data onto a
  single curve.

The generator is the novel output: unlike the notebook's visual
collapse, it is extracted from the data alone, without being told the
closed-form expression for `Pi`.
